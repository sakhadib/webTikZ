Quickstart

IIFE • ESM • npm • worker
BROWSER (IIFE)
<script src="dist/webtikz.min.js"></script>
<script type="text/tikz">
\begin{tikzpicture}
  \draw[help lines] (0,0) grid (4,3);
  \draw[red,thick] (0,0) rectangle (2,1);
\end{tikzpicture}
</script>
<!-- auto-renders on DOMContentLoaded -->
ESM / NPM
import { WebTikZ } from "webtikz";
const src = "\\draw[->,dashed] (0,0) -- (2,0);";
const pic = await WebTikZ.render(src, canvas, {
  scale:1.5, dpr: devicePixelRatio,
  theme:"light",
  onError:e=>console.warn(`${e.line}:${e.column} ${e.message}`)
});
console.log(pic.bbox, pic.nodes);
pic.on("click","a", n=>alert(n));
pic.toSVG(); await pic.toPNG(2); pic.toPDF();
HEADLESS / WORKER
// no DOM — tests, SSR, Workers
const {displayList, errors}= await WebTikZ.compile(src);
console.log(displayList.bbox);

// OffscreenCanvas worker
import {createWorkerRenderer} from "webtikz/worker";
const w = createWorkerRenderer("/dist/webtikz.js");
w.postMessage({src}, [offscreen]);
Limits enforced: 10k foreach iters, 50k items, 3s wall-time — graceful line:column errors + partial render.

API & Keys Reference

All keys are `src/keys` pgfkeys-style; unknown keys warn, don't crash.

Picture

  • compile(src, opts) → {displayList,bbox,nodes,errors}
  • render(src, canvas|el, opts) → Picture
  • Picture{toSVG(), toPNG(s), toPDF(), on, setTheme, update, destroy}
  • autoRender({selector, scale})
  • <tikz-picture fit="contain" scale="1.5"> + ResizeObserver

Keys (excerpt)

  • colors: red!30!blue, -red, defineColor, colorlet
  • transforms: shift, scale, rotate, xslant, cm
  • nodes: circle/rectangle, inner sep, minimum width, anchor, label, pin, right=of a
  • calc: ($(A)!.5!(B)$), (A |- B), let \p1=(A) in
  • arrows: Stealth[length=3mm], shorten <>
  • decorations: decorate, decoration={zigzag, brace}
  • axis: axis, addplot, semilogx, ybar, surf
